    OGC Records worden gebruikt om datasets en de bijbehorende datasetversies volgens de OGC specificatie op een gestandaardiseerde manier beschikbaar te stellen. Iedere DSO-dataset wordt ontsloten als een record collection, met metadata over deze dataset uit het Amsterdam Schema en de beschikbare datasetversies. Iedere datasetversie wordt vervolgens beschreven door een afzonderlijk OGC-record met de bijbehorende metadata en links naar de relevante WFS-services. Hierdoor kunnen kaartviewers zoals NL3D en Geosquare deze datasets en datasetversies op een uniforme manier ontdekken en de bijbehorende geografische gegevens raadplegen.

    Record collections

    Een record collection van een dataset bevat metadata zoals een identificatie, titel, beschrijving en links naar de bijbehorende records (datasetversies). Voor de OGC Records API documentatie, zie OGC API - Records. Voor een overzicht van bestaande record collections met metadata uit het schema, zie Record Collections.
