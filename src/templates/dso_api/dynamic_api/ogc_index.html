    Het Open Geospatial Consortium (OGC) is een internationale organisatie die open standaarden ontwikkelt voor het uitwisselen, publiceren en opvragen van geografische informatie. Deze standaarden zorgen ervoor dat verschillende systemen en applicaties op een uniforme manier met ruimtelijke gegevens kunnen werken. De OGC API-standaarden maken het mogelijk om geografische gegevens en bijbehorende metadata via web-API's beschikbaar te stellen en te gebruiken.

    De Records API wordt gebruikt om gegevensbronnen te ontdekken met metadata uit het Amsterdam Schema.
